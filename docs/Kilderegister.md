# Kilde-, avhengighets- og attribusjonsregister

Gjennomgått 21. november 2026. Hver GitHub-lenke peker til den undersøkte revisjonen. De sju eksterne prosjektene er lest som kildemateriale. Pakken inneholder ingen av deres filer, binærprogrammer eller installasjonsskript. Beslutningene nedenfor skiller lokal implementasjon fra mulige avhengigheter i senere faser. Gjennomgangen av tredjepartskoden er statisk.

## Eget prosjekt og format

**vestbytuva-ops/Academic-Skill** · `97db0255ddfb924a25ec0f408087f101bea530fe`. De tre originalfilene lå til grunn for den lokale piloten. Hovedfilen styrte arbeidet, og forskningsveiledningen dekket blant annet litteratursøk, studiedesign og analyser. Arbeidsmåtene er videreført i én Claude-skill. Revisjonen har ingen lisensfil eller lisensangivelse i hovedfilen. Det er ikke tildelt noen ny lisens til grunnprosjektet i denne leveransen. Avklar eventuell senere offentlig publisering med rettighetshaveren. [Filtre](https://github.com/vestbytuva-ops/Academic-Skill/tree/97db0255ddfb924a25ec0f408087f101bea530fe) · [Hovedfil](https://github.com/vestbytuva-ops/Academic-Skill/blob/97db0255ddfb924a25ec0f408087f101bea530fe/.agents/skills/academic-skill/SKILL.md) · [Forskningsveiledning](https://github.com/vestbytuva-ops/Academic-Skill/blob/97db0255ddfb924a25ec0f408087f101bea530fe/.agents/skills/academic-skill/references/forskningsverktoy.md)

Formatgrunnlaget er Agent Skills med navn og beskrivelse i YAML, en inngang i `SKILL.md` og oppgavespesifikke referanser som kan lastes ved behov. Ekstra metadata, agentdefinisjoner, filtilgang og kjøring av kommandoer må vurderes per vert. [Agent Skills-spesifikasjonen](https://agentskills.io/specification)
