# Akademisk veiledning

Ta utgangspunkt i oppgaven, brukerens egne tanker eller utkast og eventuelle vurderingskriterier. Tilpass fagord, sjanger og omfang til nivået. Still bare oppklarende spørsmål når svaret kan endre resultatet vesentlig. Gjør en rimelig antakelse synlig når den lar deg jobbe videre.

Les [felles arbeidsgrunnlag](references/arbeidsgrunnlag.md) for språkvalg, arbeidsform, belegg og personvern. Velg referansene som passer bestillingen. Hovedskillen kan brukes alene, også når oppgaven krever flere arbeidsmåter.

## Les bare referansene oppgaven trenger

| Når brukeren ber om | Les |
| --- | --- |
| Oppgavetekst, vurderingskriterier, problemstilling eller første steg | [Oppgaveforståelse](references/oppgaveforstaelse.md) |
| Disposisjon, utkast, argumentasjon, drøfting eller faglig revisjon | [Akademisk skriving](references/skriving.md) |
| Retting av avsnitt, klarere språk eller bedre flyt | [Språkvask](references/sprakvask.md) |
| Tilbakemelding, lærerrespons eller vurdering av en tekst | [Kritikk](references/kritikk.md) |
| Kontroll av kilder og henvisninger, forskning, metode eller analyse | [Kildekontroll](references/kildekontroll.md) |
| Faglig forklaring, øvelse, quiz, eksamensøving eller øvingskort | [Læring og eksamen](references/laering-og-eksamen.md) |
| Disposisjon til presentasjon, lysbilder eller talepunkter | [Presentasjoner](references/presentasjoner.md) |
| Arbeid med Word, Excel eller PowerPoint | [Office-filer](references/office-filer.md) |
| Leveransekontroll eller sammenligning av original og revisjon | [Sluttkontroll](references/sluttkontroll.md) |
| Personlig skrivestemme, stilvalg eller innsyn i en arbeidsprofil | [Personlig stemme](references/personlig-stemme.md) |

Les [engelsk akademisk skriving](references/english.md) når en engelskspråklig leveranse krever sjanger-, språk- eller sitatkonvensjoner. Bruk engelske fagbegreper og den sitatstilen oppgaven krever. Les [norsk skole](references/norsk-skole.md) bare når en norskspråklig bestilling gjelder norsk grunnskole, videregående eller norsk læreplan. Bruk de vanlige fagreferansene ved ukjent skolenivå, universitetsarbeid og engelskspråklige leveranser.
